# Ravindra Singh Portfolio

A responsive, single-page portfolio website created from the information in the uploaded resume.

## Files
- `index.html` — portfolio page
- `style.css` — responsive styling
- `script.js` — mobile menu + current year
- `assets/Ravindra-Singh-Resume.pdf` — resume download/view file
- `assets/Ravindra-Singh-Profile.jpg` — profile photo

## Free GitHub Pages hosting

1. Create a free GitHub account at https://github.com if you do not already have one.
2. Create a **New repository**.
3. Give it a name such as `ravindra-singh-portfolio`.
4. Set the repository to **Public**.
5. Upload **all files and folders** from this package. Make sure `index.html` is in the repository's main/root folder.
6. Open **Settings → Pages**.
7. Under **Build and deployment**, select **Deploy from a branch**.
8. Select the `main` branch and `/ (root)`, then click **Save**.
9. After GitHub finishes deploying, your free website will be available at:
   `https://YOUR-GITHUB-USERNAME.github.io/ravindra-singh-portfolio/`

## Important
The resume PDF is included in `assets/`, so the **View Resume** buttons work after upload.

The portfolio text follows the uploaded resume. If you want to change any phone number, email, address, photo, social links, colors, or services, edit `index.html` and `style.css`.
